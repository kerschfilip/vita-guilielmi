# Vita Guilielmi – Digital Comparative Edition

<img src="icon.png" alt="Vita Guilielmi" width="80"/>

A digital synoptic edition of the *Vita et obitus sancti Guilielmi*, comparing a 13th-century Beneventan manuscript preserved at the Abbey of Montevergine with the 1581 *editio princeps* by Felice Renda. Developed within the ANTIDOTE doctoral training network.

The edition is built with **TEI Publisher 10** running on **eXist-db**, managed with **Jinks**, and presented as a web application with synoptic reading views, facsimile images, named-entity indexes, and a geographical map.
